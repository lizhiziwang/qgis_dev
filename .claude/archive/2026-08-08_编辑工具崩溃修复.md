# 编辑工具按钮点击崩溃（0xC0000409）

日期：2026-08-08
分支：dev

## 背景

`app/ui/main_window/tool_bar.py` 新增"编辑"按钮（`QAction("编辑")` → `_on_edit_tool`，未提交），
用户点它直接 native 崩溃：PyCharm `Process finished with exit code -1073740791 (0xC0000409)`，
无 Python traceback。

顺带确认了上一任务的结论：源码（PyCharm）里有"编辑"按钮且渲染正常；用户此前看不到按钮
是因为 `dist/app/app.exe` 是 11:04 打的旧包（早于 11:48 加按钮的源码），打包版 PYZ 里根本没有
`edit_tool`/`编辑`。

## 根因

`MainWindow.__init__` 从未初始化 `self._selected_layer`（只初始化了 `self.edit_layer`）。
`_on_edit_tool` 里无条件访问它：

```python
layer = (
    self._selected_layer                    # ← AttributeError!
    if isinstance(self._selected_layer, QgsVectorLayer)
    else None
)
```

未选图层时（`edit_layer is None`）走到这里 → `AttributeError: 'MainWindow' object has no attribute
'_selected_layer'`。该异常在 PyQt5 槽内（`QAction.triggered` 信号栈）未捕获 → 本环境 native
崩溃 0xC0000409（bash 里表现为静默 exit 127）。这与 `main_window.py` 已有代码注释
"AttributeError → PyQt5 槽内未捕获 → 崩溃" 是同一类陷阱。

## 复现

离屏探针用 `action.trigger()`（不经 try/except）复现：
- 修前：`[edit-trace] step1` 后进程直接死，`trigger()` 未返回；
- 修后：`_selected_layer` 已初始化 → 走 `QMessageBox`「请先选择要编辑的矢量图层」，`trigger()` 正常返回。

同一探针验证了有图层路径（memory 层 / 真实 gpkg / 底图栅格 current layer → 矢量真切换）都不崩；
`_on_edit_tool` 本身（setCurrentLayer → start_edit_fun → setMapTool(QgsMapToolEdit)）各场景均正常。

## 修复

| 文件 | 改动 |
|---|---|
| `app/ui/main_window/main_window.py` | `__init__` 增加 `self._selected_layer: Optional[QgsVectorLayer] = None`（附注释说明崩溃原因） |

## 关键结果

- `py_compile` / 离屏探针通过：无图层点击"编辑"→ 弹提示框、不崩；有图层 → `QgsMapToolEdit` 激活、
  `layer.isEditable()==True`。
- 探针脚本与临时 `[edit-trace]` 日志已全部清理；探针写入的 `%APPDATA%\qgis_dev\credential.json`
  （username=probe）已删除，恢复登录弹窗。

## 备注

离屏探针环境自身有与编辑无关的崩溃：启动后加载天地图 XYZ 底图，退出 teardown 时
"Windows fatal exception: access violation"（exit 139）。与编辑工具无关（无编辑调用的控制组也崩），
是离线/渲染 teardown 的环境噪音。
