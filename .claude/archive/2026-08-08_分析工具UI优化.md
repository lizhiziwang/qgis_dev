# 分析工具 Dock 与工具树 UI 布局/交互优化

日期：2026-08-08
分支：dev

## 背景

用户请求 `@app/ui/docks/analyse_dock.py` 优化"分析工具"的 UI 布局和工具树布局与交互。
真正显示的"分析工具"dock 是 `app/ui/docks/tools_dock.py` 的 `ToolsDock`（工具条"分析"
按钮创建），`analyse_dock.py` 的 `AnalyseDock` 是未使用占位类（历史归档
`2026-08-06_矢量缓冲区工具.md` 已确认过"真正 dock 是 ToolsDock"）。

现状问题：每次点"分析"都新建一个 dock（越点越多）；树只有单一"矢量常规"分组、无搜索/
展开折叠/右键菜单/tooltip/内边距。

## 做了什么

| 文件 | 改动 |
|---|---|
| `app/ui/docks/tools_dock.py` | **核心**。内容改为 `QVBoxLayout`(margin 8)；顶部工具条 = 搜索框(`QLineEdit`, placeholder"搜索工具…", 实时过滤) + "展开"/"折叠"两个 `QToolButton`。树按类别分两组：**矢量分析**（矢量缓冲区/叠加分析/最短路径分析/重投影）、**数据导出**（生成矢量瓦片XYZ）；分组加粗、叶子 `setSizeHint(QSize(0,28))` 统一行高 + `setToolTip` 一行说明；`setAnimated/setIndentation(18)/setUniformRowHeights`；默认全展开。交互：保留单击打开 + 新增 `itemActivated`（双击/回车）复用同一 `_on_item_clicked`；右键菜单（叶子→"打开工具"，分组→"展开/折叠"）；`_apply_filter` 空串恢复全显并展开、非空隐藏不匹配叶子/无匹配分组、分组名命中则整组显示并展开。`_DIALOG_FACTORIES` + `self._dialogs` 复用逻辑原样保留 |
| `app/ui/main_window/main_window.py` | `_on_analyse` 改为复用单实例（`self._analyse_dock`），不再每次点击新建 dock |
| `app/ui/docks/analyse_dock.py` | 占位类改为兼容别名：`AnalyseDock = ToolsDock`（仓库内无外部 import，零风险） |
| `tests/ui/docks/test_tools_dock.py` | 树由单分组改多分组后，硬编码索引断言失效 → 新增 `_find_item_by_code`/`_leaf_items` helper，按 `_code_` 查节点、遍历所有分组叶子 |

## 关键结果

- `py_compile` 四个文件通过。
- 非 GUI 全量：`65 passed, 17 skipped, 18 deselected`（PyQt5 不可用模块按惯例跳过）。
- **真实 QGIS 3.40 GUI 回归**（`.tmp/run_gui_tests.py` bootstrap + QGIS python）：
  `tests/ui/docks/test_tools_dock.py -m gui` → **2 passed**（对话框复用、不同工具独立实例）。
- **离屏探针**（`probe_dock_ui.py`，已验证后清理）：分组结构/默认展开/tooltip ✓；过滤"缓冲"命中
  矢量缓冲区且隐藏其余、"xyz"命中矢量瓦片、清空恢复全显全展开 ✓；折叠/展开全部 ✓。

## 遗留事项 / 观察

- 搜索框过滤后清空会重新展开所有分组（含用户手动收起过的），语义简单直接，如不想要可改成记住展开状态。
- dock 内未加算法描述（用户此前明确只要纯工具树，描述在对话框右侧）；如需可复用 `app/ui/common/algo_desc.py`。
- 实机冒烟（真实应用点"分析"验证交互）待用户复测：dock 复用、搜索过滤、双击/回车、右键菜单。
- 临时 `.tmp/qgis_pytest`（本次装的 throwaway pytest）与 `probe_dock_ui.py` 已清理；`.tmp/pytest_qgis` + `.tmp/run_gui_tests.py` 是既有共用工具，保留。
