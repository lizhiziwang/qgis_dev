# 2026-08-13 流程编辑器删除节点崩溃修复

## 背景

用户报告：`app/ui/flow_editor/` 流程编辑模块，删除节点导致程序崩溃，输出
`QThreadStorage: entry N destroyed before end of thread ...`。首轮修复后用户反馈
「依旧会进程崩溃」，需在真实 `FlowEditorWindow` 环境下复现并修正。

## 根因

`QGraphicsScene.removeItem(item)` 之后，若 Python GC 立即释放图形项的 C++ 对象，
场景/视图仍挂着未处理的移除重绘，下次 `processEvents()` 重绘访问悬空内存 → 崩溃。
与 `QGraphicsDropShadowEffect`、是否选中无关。

**真实窗口下的关键发现**（探针逐项隔离）：
- 单节点/单次删除：`processEvents` 快速处理完重绘，定时释放偶发安全；
- **连删两次以上**：第一次删除的节点被 50ms 定时器释放时，真实窗口里重绘尚未
  结束 → 必崩（3/3 稳定复现）。崩溃点在第 2 次删除后的 `pump()`。
- 对照：墓碑列表**永不释放**（保持项存活），连删 3 个节点 3/3 全通过。
- 结论：**定时释放的「等到安全」是脆弱启发式**，真实窗口渲染节奏下不可靠。

## 做了什么

**最终修复**（`app/ui/flow_editor/scene.py`）：删除节点时把 `removeItem` 后的
`NodeItem` 收进场景 `_deleted_items` 墓碑列表，**只在下次 `rebuild()` 的
`clear()`（Qt 批量清理，保证无未处理更新）之后清空释放**：

```python
def remove_node(self, node_id):
    ...
    item = self._node_items.pop(node_id, None)
    if item is not None:
        self.removeItem(item)
        self._deleted_items.append(item)   # 保持存活，不释放
    ...
    self._graph.remove_node(node_id)
    self._rebuild_edges()
    self.graph_changed.emit()

def rebuild(self):
    self.clear()
    self._deleted_items.clear()   # clear() 后安全释放墓碑
    ...
```

- 彻底去掉第一轮的不充分修法：`setGraphicsEffect(None)`（单独无效）和
  `QTimer.singleShot(50, ...)` 定时 flush（真实窗口连删必崩）。
- 内存有界：墓碑只在换图 / 新建 / 重置（触发 `rebuild`）时释放，编辑会话内保持
  少量已删项存活（每项 ~几十 KB，可接受）。

## 关键结果

真实 `FlowEditorWindow`（含 QSS / 主题 / dock / 参数面板）3 次全通过：
- 删中间 B（入边+出边）→ 删 A → 删 C，墓碑 = 3，长 pump 不崩；
- `set_graph`（rebuild）后墓碑清为 0（内存释放生效）；
- 换图后再删、右键 `remove_node`、连删 6 轮 + 持续 pump —— 全部 OK，退出码 0。

探针文件已全部清理。

## 追加修复：删除后节点仍残留在画布上

墓碑方案修好崩溃后，用户反馈「删除流程节点之后，画布上还显示节点」——视觉上
没消失。经探针定位（真实窗口 + 独立场景对照）：

**根因**：`removeItem(item)` 把项从场景顶层列表移除（`scene.items()` 已无它），但
**场景 BSP 索引**仍残留该项（`scene.items(rect)` 命中测试仍能找到 node2），绘制
正是用该索引取可见区域的 items，于是节点一直被画出来。任何强制重绘
（`scene.update()` / `invalidate()` / `view.repaint()` / 视口 grab）都清不掉——
因为索引里就有它。

**为何裸 `removeItem` 的探针是干净的**：只有完整删除路径（选中 + 高亮链 +
`_rebuild_edges` 重建边）才触发残留；最小用例 + 单独 `removeItem` 不残留。判断
与选中/高亮导致的项状态变化有关，但机制不必深究——修复已验证对全部路径生效。

**修复**（`app/ui/flow_editor/scene.py` 的 `remove_node`）：先 `item.hide()` 再
`removeItem(item)`。`hide()` 会立即停止绘制并让场景清理该索引区域，即使索引有
残留也画不出来。墓碑（延迟释放）逻辑不变：

```python
item = self._node_items.pop(node_id, None)
if item is not None:
    item.hide()                     # 先隐藏：清掉 BSP 索引残留区域，立即停止绘制
    self.removeItem(item)
    self._deleted_items.append(item)  # 延迟释放，见 __init__ 注释
```

**验证**（真实 `FlowEditorWindow`）：
- 视觉：删中间节点 B，其区域非背景像素 5290 → 0，BSP 命中 0，`scene.items()`
  节点数正确；
- 崩溃回归：连删 A/C（右键 `remove_node` + Delete 路径）、多选连删 A+C、
  换图（rebuild）后墓碑清 0、换图后再删、长时泵浦 —— 全部通过，退出码 0。
