# 2026-08-26 通用工具条：卷帘对比工具

## 需求

在通用工具条加一个「卷帘对比」工具：弹窗选 **底层栅格 / 对比栅格 / 方向（垂直/水平）**，
确认后画布只显示底层栅格（纯双影像对比，矢量临时隐藏），对比栅格离屏渲染成 QImage，
经透明子 QWidget 覆盖层绘制在可拖动分割线的一侧；拖动分割线在两张影像间切换。
Esc 或切换任意其它工具即退出，还原原图层集、移除覆盖层。

## 关键设计 / 非显然点

1. **覆盖层用 canvas 子 QWidget**（本构建无 `setOverlayWidget`、无
   `QgsMapCanvasItem.setItemPositionFixed`）：`WA_TransparentForMouseEvents` 让鼠标
   穿透到 viewport → 当前 QgsMapTool 收事件拖动；`WA_TranslucentBackground` +
   `WA_NoSystemBackground`；`raise_()` 在 showEvent / mapCanvasRefreshed /
   extentsChanged 时重提（底层渲染会在 viewport 内重绘盖住覆盖层）；canvas + viewport
   的 `eventFilter(Resize)` 同步几何。仓库既定模式见 `canvas_zoom.py`。
2. **离屏渲染**：`QgsMapSettings(canvas.mapSettings())` 深拷贝 → `setOutputSize(
   viewport().size())`（逻辑像素）+ `setDevicePixelRatio(viewport().devicePixelRatioF())`
   → `setLayers([compare])` → 校验 `hasValidSettings` + 非空 extent →
   `QgsMapRendererParallelJob` 异步渲染。`renderedImage()` 自带 DPR，画到逻辑矩形即
   1:1 高清。
3. **重渲染节流**：extentsChanged / magnificationChanged / rotationChanged → 置
   `_needs_render` + `QTimer.singleShot(0, ...)`（`_render_scheduled` 最多排一个）；
   渲染中 `job.isActive()` 则等 finished 后再拾取 pending。**绝不在 Qt 事件栈内**
   `canvas.refresh()` / `zoomScale` / `unsetMapTool`（仓库既定 0xC0000409 约束，一律
   singleShot(0, ...) 推迟出栈）。
4. **过期 job 淘汰**：`_render_seq` 单调递增，`_start_render` 时 `++` 并 `cancel()` 旧
   job；`finished` 回调校验 `seq == _render_seq`，对不上直接忽略。
5. **退出还原**：`deactivate()` 先置 `_active=False`、断信号、`_cancel_job()`、删覆盖层；
   图层还原 `singleShot(0, ...)` 推迟出栈（新工具已先激活，不打架），还原 `__init__`
   里捕获的 `canvas.layers()`，按工程中仍存在的图层过滤。
6. **图层守卫**：`layersChanged` → 底层被移除则退出；桥接器改回多图层则重断言
   `setLayers([base])`（`_restoring` 标志防回环）。
7. Qt6 鼠标用 `event.pixelPoint()`（无 x()/y()）；Esc → `event.ignore()` +
   singleShot → `unsetMapTool`。光标垂直 `SplitHCursor` / 水平 `SplitVCursor`。
8. **测试环境**：必须用 `python-qgis.bat` + 仓库 `.tmp/run_pytest_qgis.py` 引导
   （QGIS 4.2 OSGeo4W Python 3.12 才带完整 PyQt6 + qgis.core）。GDAL 用 `band.Fill()`
   造 8×8 GeoTIFF，不依赖 numpy。

## 修复（同日，分屏时矢量不渲染）

**Bug**：用户原决策是「仅底层栅格」，实际使用时要求分屏期间矢量照常渲染。
原 `_set_base_only` 把画布强制成 `[base]`，`_on_layers_changed` 又把图层树桥接器
（`QgsLayerTreeMapCanvasBridge`，main_window L128）加进来的矢量清掉 → 矢量永不显示。

**改动**（`app/ui/tools/swipe.py`，语义从「只显示底层」改为「显示原图层集去掉对比栅格」）：

- `_set_base_only` → `_set_layers(layers)`（通用设置 + `_restoring` 防回环）+
  `_set_base_content`：画布 = `_orig_layers` 去掉对比栅格（按 `id()` 过滤，防桥接器
  用不同包装对象），底层不在其中则补进。
- `_on_layers_changed`：底层被移除仍退出卷帘；其余情况**不再重断言** —— 桥接器加新
  矢量保留；若桥接器把对比栅格加回画布则剥掉（singleShot + `_set_layers`）。
- docstring / main_window `_on_swipe` 同步更新。

**测试**：新增 `test_swipe_keeps_vector_layers` —— 接真实 `QgsLayerTreeMapCanvasBridge`，
断言激活后画布 = [base, vector]（compare 剥掉）；分屏期加 vector2 → 桥接器加入、不被
卷帘清掉、compare 仍不在。

**验证**：`tests/ui/main_window/ -m gui` 40 passed（原 39 + 新 1），无回归；
`ruff format --check` 干净；`main_window.py` 的 format 漂移是既有（HEAD 版本同样不过），
本次未动。

## 修复（同日，视图状态常驻 + 矢量两侧都可见）

**需求**：①编辑（画要素）时自动退出分屏 → 改为**视图状态常驻**：切到任意工具
（平移/缩放/画要素/查询）分屏保留，再点「卷帘对比」恢复分隔条拖拽，Esc 才退出。
②两幅影像都应是底层、矢量在**两侧**都显示在影像之上（右/下侧不能再被对比影像盖住）；
对话框标签改为 左（上）影像 / 右（下）影像。

**架构决策（用户选「矢量两侧都可见」）**：覆盖层是 canvas 子 QWidget，永远盖在
画布渲染之上 → 矢量在覆盖层之上显示的唯一办法是把矢量也**离屏渲染进覆盖层**。
由此画布职责简化为只画**左（上）影像**；右（下）影像 + 其它图层（矢量等）分别
离屏渲染成 QImage，由覆盖层 `paintEvent` 合成：右影像按分割线 `setClipRect` 裁剪，
矢量（透明背景）画在**整个**画布（两侧影像之上）。拖动只改 clip，不重渲染。

**改动**：

- `app/ui/tools/swipe.py`（重写核心）：
  - `SwipeOverlay`：`set_image` → `set_images(compare, others)`；`paintEvent` 先画
    裁剪的右影像，再全幅画 `others_image`（矢量在两侧影像之上），最后画分隔线+手柄。
  - `SwipeTool` 双标志：`_alive`（会话存活：覆盖层+渲染工作中，切工具保持）/
    `_active`（本工具是当前工具）。`deactivate()` 变 no-op，只有 `_exit_session()`
    （Esc / 左影像被移除）才断信号、取消渲染、删覆盖层、还原图层集。
  - `_set_base_content`：画布 = `[base]`（只留左影像）；`_others` = 原图层集去掉
    两影像，交给覆盖层离屏渲染。`_on_layers_changed`：以桥接器当前画布集为准更新
    `_others`（新增矢量也纳入），再 singleShot 重断言画布 `[base]`。
  - 渲染：每帧两个并行 job（compare + others），`_pending` 计数，都完成才
    `_apply_images` 合成。`_job_connections` 存 `finished` 连接，`_cancel_jobs` 里
    **先 disconnect 再 cancel**——杜绝取消后 job 的 `finished` 打到已拆会话上；
    `_on_render_finished` 用 `getattr(self, "_alive", False)` 守卫（画布删除后
    PyQt6 会清空 wrapper 的 `__dict__`，直接 `self._alive` 会 AttributeError）。
- `app/ui/dialogs/swipe_compare.py`：标签 `左影像/右影像`（垂直）/`上影像/下影像`
  （水平），`_update_orientation_labels()` 随方向联动；`selected_params` docstring

**测试环境踩坑（QGIS 4.2 + pytest-qt）**：

1. **`win` fixture + `two_rasters` 组合在 teardown 必然堆损坏**：真实 MainWindow 的
   `QgsLayerTreeMapCanvasBridge` 挂在共享单例上，teardown 移除图层 → 桥接器 churn →
   `w.close()` 后 pytestqt `_process_events` 0xC0000374。单独验证过（无 swipe 也崩）。
   恢复测试因此**不用这两个 fixture**：独立 `QgsProject` + 裸 `QgsMapCanvas` +
   仅暴露 canvas/project 的 `_FakeWin`，把真实 `MainWindow._on_swipe` 绑上去。
2. **Shutdown GC 段错误**：`_FakeWin ↔ tool` 循环（`parent_window`/`_swipe_tool`）

   测试结尾必须：`_exit_session()` → `unsetMapTool` → `deleteLater` → 断循环引用 →
   `gc.collect()`（QApplication 存活时）。
3. 每个建了 swipe 会话的测试结尾都要 `_exit_session()` + `processEvents()`，否则
   异步渲染 job / 信号连接残留导致 teardown 段错误。
