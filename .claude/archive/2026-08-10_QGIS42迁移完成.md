# 会话归档：QGIS 3.40 (Qt5) → 4.2 (Qt6/PyQt6) 迁移

日期：2026-08-10
分支：dev

## 背景

用户 QGIS 从 `D:/zsh/app/qgis_3.40`（Qt5/PyQt5，Py 3.10）升级到
`D:/zsh/app/qgis4.2`（Qt6/PyQt6，Py 3.12）。应用 `app/` 全部基于 PyQt5 +
QGIS 3.40 API，在 4.2 无法运行。用户确认「一并更新打包配置」。

## 做了什么

1. **运行时环境适配 4.2 布局**（`app/env/qgis_runtime.py`、`config/app.yaml`、
   `app/bootstrap/__init__.py`）：`qgis_ltr` → `qgis_prefix`（`apps/qgis`）、
   新增 `qt6`、`proj = share/proj`；`apply_env()` 的 PROJ_DATA/GDAL_DATA/
   QT_PLUGIN_PATH 按新布局。bootstrap 探测路径 `apps/qgis-ltr` → `apps/qgis`。

2. **PyQt5 → PyQt6 全局迁移**：62 个文件导入替换；`QAction` 从 QtWidgets 移到
   QtGui（6 处拆 import）；`from qgis.PyQt.*` → `PyQt6.*`；`QVariant` 保留
   （4.2 兼容 shim 探针确认可用）；`.exec_()` → `.exec()`。

3. **枚举限定名**（PyQt6 强制，`Qt.AlignCenter` 等裸枚举全部 AttributeError）：
   `Qt.*` 命名空间 → `Qt.AlignmentFlag.*`/`GlobalColor.*`/`ItemDataRole.*` 等
   （16 文件脚本化替换）；控件类枚举 → `QMessageBox.StandardButton.*`、
   `QAbstractItemView.SelectionMode.*`、`QHeaderView.ResizeMode.*`、
   `QLineEdit.EchoMode.Password` 等。

4. **QGIS 4.x API 变化**：
   - `QEvent.WindowStateChange` → `QEvent.Type.WindowStateChange`（**未限定会
     在事件处理器里硬崩溃** exit 127 无 traceback，靠文件探针定位）。
   - `QDockWidget.AllDockWidgetFeatures` 在 PyQt6 **不存在** → 显式 OR
     Closable|Movable|Floatable。
   - `QgsMapToolShapeCircle/Rectangle` 在 4.2 移除 → 委托自定义
     `CircleDrawTool`/`RectangleDrawTool`。

5. **打包配置升级**（用户确认）：`tools/pyinstaller.spec`（实际构建用的）和
   `app/app.spec`、`tools/build_windows.ps1`（`python-qgis.bat`、
   `apps/qgis` 布局）、`README.md`。Qt6 DLL + qgis_native.dll/qgispython.dll、
   Qt 平台插件从 `apps/qt6/plugins/platforms`。

6. **测试环境适配**：6 个 conftest 加 `python/plugins` 到 sys.path（4.2 不再
   自动加）；check conftest 的 `QgsApplication(sys.argv, True)` → bytes argv
   （PyQt6 要求，buffer/overlay/ui 早已如此）；`.tmp/run_pytest_qgis.py`
   wrapper 加 `apps/qgis/python`（绕过 python3.bat 清空 PYTHONPATH）。

## 修复的关键 bug

- **主窗口构造硬崩溃**（exit 127 无 traceback）：`changeEvent` 里未限定
  `QEvent.WindowStateChange` → PyQt6 AttributeError 在事件处理器内 → 硬崩溃。
- **check 注册表为空**：测试 autouse fixture `reset_registry()` 清空注册表后，
  重 import `builtin` 是 no-op（sys.modules 缓存），`value_range` 丢失 →
  KeyError。修复：fixture 里 `importlib.reload` 每个 builtin 子模块重新跑
  `@register`。**不是 4.2 回归，是测试设计缺陷被迁移暴露**。
- **`tests/infra/test_messagebar.py` 打 patch 打错模块**：`_get_bar` 在
  `qgis_bar` 模块，`send` 在自己模块 globals 里查它，patch 包命名空间永远
  不生效。改 patch `qgis_bar._get_bar`。同样是既有测试 bug。

## 冒烟结果

- QGIS 4.2 Python 全量 pytest **全绿**（含 UI 26/26、env 9/9、check 33/33），
  仅 1 个预期 skip（fastapi 未装）。
- offscreen 主窗口 smoke 通过（`build_window` 构造 + 事件循环不 exec）。

## 遗留/注意

- 打包的 Qt6 DLL 清单是依赖分析出的最小核心集，构建时缺 DLL 再补。
- 产物 `tools/dist/app/config/app.yaml` 是上次构建遗留，重新构建后覆盖。
