# 新增「影像切片（MBTiles）」工具

日期：2026-08-10
分支：dev

## 背景

在「影像切片（XYZ 目录）」工具基础上，用户新增一个工具，用
`native:tilesxyzmbtiles` 输出**单个 .mbtiles 文件**（SQLite 内嵌 XYZ 瓦片
金字塔），便于分发 / 离线使用。

## 算法要点（`native:tilesxyzmbtiles`，release-3_40 源码确认）

- 与 `tilesxyzdirectory` 同属 `QgsXyzTilesBaseAlgorithm`，**同样按画布渲染**
  （图层树所有可见图层逐瓦片重渲染），耗时特性一致（METATILESIZE、瓦片数
  主导）。探针验证普通 `threading.Thread` 运行稳定，不崩溃。
- 参数（比 directory 版更少，探针运行时确认）：`EXTENT / ZOOM_MIN / ZOOM_MAX /
  DPI / BACKGROUND_COLOR / ANTIALIAS / TILE_FORMAT / QUALITY / METATILESIZE /
  OUTPUT_FILE`；**无** TILE_WIDTH/HEIGHT（固定 256×256）、无 HTML/TMS 参数。
- 输出：单个 .mbtiles，内部 `metadata` + `tiles` 表；瓦片按 **TMS** 规范存储
  （`setTileData(z, x, tile2tms(y, z), ...)`）；metadata 记录 format/minzoom/
  maxzoom/bounds。
- 每级瓦片数经 `pushInfo` 报（directory 版用 `pushWarning`），日志级别不同但
  反馈类都捕获。

## 后续：生成网页预览 HTML

用户要求 MBTiles 工具也生成预览 HTML。`native:tilesxyzmbtiles` 本身**没有**
HTML 输出（源码确认：initAlgorithm 只有 OUTPUT_FILE），且浏览器读不了 SQLite
格式的 .mbtiles。方案：切片完成后把瓦片从 mbtiles 解出成目录 + 生成与
directory 版同款的 Leaflet 页面。

改动：

| 文件 | 改动 |
|---|---|
| `app/core/domain/imagery_mbtiles/service.py` | `ImageryMbtilesJob` 加 `html: bool = False` 字段 |
| `app/core/domain/imagery_mbtiles/task.py` | 成功后若 `job.html` 调 `_write_preview_html()`：用 sqlite3 读 mbtiles 瓦片 → 按 XYZ 写 `{文件名}_preview/{z}/{x}/{y}.png` → 写 `index.html`（Leaflet 1.9.4 CDN，相对路径瓦片，中心/缩放取自 metadata 的 bounds/minzoom/maxzoom） |
| `app/ui/dialogs/imagery_mbtiles.py` | 加「生成网页查看器（HTML）」复选框；完成提示含预览 html 路径 |
| `app/ui/common/algo_desc.py` | 描述补「网页查看器」一段 |

要点：

- MBTiles 的 `tile_row` 存的是 **TMS** 行号（算法写入时经 `tile2tms`），
  解到 XYZ 目录需换算 `xyz_y = 2^z - 1 - tms_y`。
- 预览 HTML 用相对路径 `{z}/{x}/{y}.{ext}`，双击打开即可；预览目录只是
  mbtiles 的旁产物，mbtiles 仍是唯一分发文件。

验证（`_probe_mbt_html.py`，已清理）：9 瓦片 mbtiles → 9 张瓦片完整解出、
Y 换算 0 不匹配、index.html 含 `L.tileLayer` 与瓦片模板、任务 completed 无异常。
