# 2026-08-26 对话框基类：无边框 + 精简标题栏

## 需求

流程编辑器边框不要完全复用 mainwindow 的——**用户信息 / 主题切换 / 模式切换**
不进流程编辑器窗口边框。做一个 **Dialog 基类**复用主窗口的无边框边框，但只保留
**图标 / 窗口名 / 最小化 / 最大化 / 关闭**；项目中所有 dialog 都继承它
（登录对话框用户已确认「一起改」）。

## 关键坑（非显然，已踩过）

1. **Qt 布局重挂坑**：`parentLayout.addLayout(subLayout)` **不会**重挂无父子布局里
   已存在的子控件；只有 `QWidget.setLayout()` 才触发重挂。BaseDialog 必须用
   `_content` 容器 + `setLayout` 路由，不能 `addLayout` 进 `_frameless_layout`，
   否则内容全消失。
2. **`QVBoxLayout(self)` 父构造式布局会被静默忽略**：dialog 已有
   `_frameless_layout`，Qt 不再套新布局 → 内容不显示。6 处全部改无父布局。
3. **`QDialog.exec()` 真模态坑**：flow_editor 冒烟测试里 `_run_flow() →
   RunParamsDialog.exec()` 会真阻塞（QgsApplication 无交互事件循环时 exec 不返回）。
   原 `_no_dialogs` fixture 只 patch 了 QMessageBox、没 patch `QDialog.exec`，
   `test_run_success_flow` 一直失败、多测试合跑时直接挂起（我改 BaseDialog +
   FramelessWindowHint 后才暴露）。修复：fixture 里加
   `monkeypatch.setattr(QDialog, "exec", lambda self: QDialog.DialogCode.Accepted)`，
   顺带把本来失败的 `test_run_success_flow` 修好了。
4. **pre-QGIS 依赖链**：`app.ui.main_window` 包 `__init__` 原来 eager import
   MainWindow → QGIS。登录对话框在 `initQgis` 之前构造，BaseDialog →
   `enable_frameless` → import `title_bar` 会炸 `ModuleNotFoundError: No module
   named 'qgis'`。改成惰性 `__getattr__` 后全链路 pre-QGIS 可构造（脚本验证：
   TitleBar 装配正常、user/theme/mode 全 None、FramelessWindowHint 置位）。
5. PyQt6 `FramelessWindowHint` = `0x800`（2048），不是 0x80000。
