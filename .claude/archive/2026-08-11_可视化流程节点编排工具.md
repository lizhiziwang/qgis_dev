# 2026-08-11 可视化流程节点编排工具

## 目标

在 PyQGIS 上做一个可视化流程节点编排工具：画布拖节点建流程、连线表达数据流依赖（带端口类型校验）、每个节点含「输入配置 / 输出配置 / 执行逻辑」三块编辑区，按拓扑序整跑或单节点分步执行，支持 JSON 导入导出、日志面板、依赖链高亮。

**已确认决策**：目标 QGIS **4.2 + Qt6 + PyQt6**（Python 3.12，`D:/zsh/app/qgis4.2`）；**集成进 `app/` 并加菜单入口**，不做独立插件目录。

## 交付内容

分层：纯逻辑（不依赖 QGIS/Qt）在 `app/core/domain/flow`，画布交互在 `app/ui/flow_editor`。

- **纯逻辑**：`types.py`（PortType 枚举 + `can_connect` 类型兼容矩阵）、`model.py`（FlowGraph/NodeSpec/InputSpec/OutputSpec/EdgeSpec dataclass）、`topo.py`（Kahn 拓扑排序 + 环检测 + 祖先/子孙）、`serialization.py`（FlowCodec schema v1，坏边容错收集 warnings）、`executor.py`（FlowExecutor：输入解析归一 → 代码编译执行 → 输出落盘/入工程/缓存，QObject 信号推 UI）、`algorithm_library.py`（6 个内置模板 + 处理工具箱算法描述桥接）。
- **画布 UI**：`scene.py`（节点/连线持有 + 端口拖拽建连 + 模板 drop）、`view.py`（滚轮缩放/框选/Delete）、`node_item.py` + `edge_item.py`（贝塞尔曲线 + 箭头 + 状态色 + 高亮）、`param_panel.py`（通用/输入/输出/执行逻辑三 tab）、`node_library.py`（左侧节点库拖拽）、`log_panel.py`、`window.py`（三栏装配 + 工具条 + JSON + 脏标记）。
- **接入**：`menu_bar.py` 新增「流程(&W)」菜单（Ctrl+Shift+F）；`main_window.py` 懒建单实例 `_open_flow_editor`；`tools_dock.py` 新增「流程编排」分组，走 `_SIMPLE_ACTIONS`（flow 编辑器返回 None，不适用 `_DIALOG_FACTORIES` 契约）。

## 关键事实（QGIS 4.2 实测）

- `QgsVectorFileWriter.writeAsVectorFormatV3(layer, path, QgsCoordinateTransformContext(), options)` —— **4 个必填参数**（V2 同为 4 参）。
- headless 跑 processing：`qgis.processing.run` 是 stub，必须 `import processing` + `Processing.initialize()` 后 native 提供方才注册；插件目录 = `Path(prefixPath()) / "python" / "plugins"`（`pythonPluginsDir()` 在 4.2 不存在）。
- `QgsLayerTreeLayer.name()`（非 `.layerName()`）。
- `processing.run` 的 INPUT 传图层对象（memory 图层带 uid 参数无法按 source 重载）；memory 输出返回图层对象、文件输出返回路径字符串。
