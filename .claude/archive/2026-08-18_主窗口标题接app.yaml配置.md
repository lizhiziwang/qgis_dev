## 实现

- **`AppConfig.app_name`**（`app/env/config.py:17, 35`）已存在且 `config/app.yaml`
  里已有 `app.name: qgis_dev`，所以本任务只做"消费侧"接线，不动配置 schema。
- **`StartupSplash.__init__(app_name="qgis_dev")`**：`app_name` 作为新参数（默认
  保留 "qgis_dev" 以便现有无参测试可用），`_build_ui` 同步接参；标题 QLabel 用它。
- **`MainWindow.__init__(project_root, app_name="qgis_dev")`**：存到 `self._app_name`；
  默认标题 / 新建工程后 / 打开工程后 三处 `setWindowTitle` 都改用它（带前缀拼接）。
- **`bootstrap.main_window.build_window(app_name)`**：从启动入口透传 `cfg.app_name`。
- **`bootstrap._start_splash(app_name)`**：同步加参数；`_run_qgis_app` 里
  `splash = _start_splash(cfg.app_name)`、`window = build_window(app_name=cfg.app_name)`。

## 用户改动

把 `config/app.yaml` 里 `app.name` 改成想要的名字即可，**不需要改任何代码**：

```yaml
app:
  name: 我的应用   # 启动 splash + 主窗口标题都会变
```

如果改了 `app.name`，**第一次启动时记得备份/迁移以下位置**（旧值写死了）：
- `%APPDATA%\qgis_dev\credential.json` → 迁移到 `%APPDATA%\<新名>\credential.json`
- QSettings 组织/应用键（``HKEY_CURRENT_USER\Software\qgis_dev\qgis_dev``）
  → 改后旧主题设置不被读取（首次启动会回到默认主题）
- 主题缓存 PNG ``%TEMP%\qgis_dev_*.png`` → 改后旧缓存失效（无害，只是重新生成）

如果名字常改，建议给上述三处也改成"统一配置"，可作为后续任务跟进。
