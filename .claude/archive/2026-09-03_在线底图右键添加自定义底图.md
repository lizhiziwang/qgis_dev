# Dock 右键「添加自定义底图」：弹窗配置 XYZ / ArcGIS / OGC WMS / OGC WMTS

日期：2026-09-03

## 背景

承接 [[2026-09-02_通用工具条在线底图Dock]] 的 Dock 右键菜单。用户追加需求：
「右键菜单还要支持添加自定义底图，点击之后弹窗设置自定义底图，自定义的底图需要
支持 arcgis 服务，ogc 服务。」

裁决（AskUserQuestion，均定稿）：
- 确定后 = **进 Dock 树 + 写回 `config/app.yaml`**（与模板入库同语义），**不**立即加载画布（双击再出图）。
- OGC 覆盖 **WMS + WMTS**；ArcGIS 指 **MapServer / ImageServer 栅格影像服务**。
- 图层/矩阵集 **手填**（不联网抓 GetCapabilities；内网发布者已知图名）。

类型词汇表（写进 yaml `type:` 键）：`xyz` | `arcgis` | `wms` | `wmts`；缺省/未知回退 xyz 路径
（老手工条目、打错类型都不炸）。

## 做了什么

### 1. `app/env/config.py` — 数据模型扩展

`OnlineBasemapDef` 追 `layers/styles/format/crs/tile_matrix_set`（默认 ""，不破坏 frozen 继承顺序）。
- `from_dict` 新字段 None→"" 兜底（手工 yaml `layers:` 空值防 None 毒化相等性）。
- `to_dict` **类型感知**：arcgis → 只 group/name/type/url；wms/wmts → + 非空 layers/styles/format/crs
  （wmts 再 + tile_matrix_set），**不写** zmin/zmax/referer；其余 → xyz 老形状不变。现有 xyz roundtrip 字节不变。

### 2. `app/core/domain/basemap.py` — 纯 uri 构造 + 分派建层

- `build_wms_uri(d)` = `url=` + `quote(url, safe=":/?={}")`（沿用「只转义 url 内 `&`」坑 1 约定）
  + 非空 layers/styles/format/crs 原样拼接。
- `build_wmts_uri(d)` = build_wms_uri + `&tileMatrixSet=`。
- `build_online_basemap_layer(d)`：xyz → 沿用 `build_base_tile_layer`；arcgis → `QgsRasterLayer(url, name,
  "arcgismapserver")`（REST 服务 URL 即 source，服务端自发现）；wms/wmts → provider "wms"。非 xyz 首载会拉
  capabilities（联网），isValid 判失败返回 None；未知 type / 异常 → log + None。

### 3. `app/ui/dialogs/custom_basemap.py` — 新弹窗 `CustomBasemapDialog(BaseDialog)`

QFormLayout（名称/分组默认「自定义底图」/服务类型 combo userData=type/服务地址）+ QStackedWidget 四页：
- xyz：referer 可选、zmin/zmax spin（0-24，默认 0/18）；
- arcgis：仅提示「以 /MapServer 或 /ImageServer 结尾」；
- wms / wmts：图层名必填（placeholder 提示，非默认文本）/ 样式可选 / 格式默认 image/png / CRS 默认 EPSG:3857，
  wmts 多瓦片矩阵集默认 EPSG:3857。
`_validate() -> Optional[str]`：name 非空、url http(s)、xyz 含 `{x}{y}{z}`、arcgis 结尾、wms/wmts 图层必填 +
  各字段禁 `&`/`=`。`_on_ok`：错 → QMessageBox.warning；对 → accept。`basemap_def()` 组 dict → from_dict。

### 4. `app/ui/main_window/main_window.py`

- 去重 url-only → **复合键 (type,url,layers)**（两个 WMS 同 base url 不同 layers 不误判重；xyz 模板 layers 空 → 等价 url 判重）。
- `_on_online_basemap` dock 构造加 `on_add_custom=self._add_custom_basemap`。
- 新 `_add_custom_basemap()`：弹窗 → exec Accepted → `_add_online_basemap_template(dlg.basemap_def())`
  （免费获得文本写回 + 刷新树 + 复合去重 + messageBar）。**不进画布**（决策）。
- `_add_online_basemap`（双击出图）改走 `build_online_basemap_layer` 分派。

### 5. `app/ui/docks/online_basemap_dock.py`

`__init__` 加 `on_add_custom`；`_build_context_menu` 在模板子菜单后加分隔 + 顶层「添加自定义底图」；
新 `_add_custom()` 无回调返回 False。

### 6. `config/app.yaml`

注释头补自定义底图说明：type 取值 + 非 xyz 不写 zmin/zmax/referer + url 用普通 `&`（勿写 `&amp;`）。

## 踩坑

- **Hint 文本被当成默认值**：wms 页图层/样式字段用 `_new_edit("如 base:图层…")` 把提示塞成了**实际文本**，
  → `layers` 恒非空，必填校验永远不触发，确定后 def 还会带上占位串。该 bug 直到补跑 dialog 测试才暴露
  （dialog 测试**不带 `@pytest.mark.gui`**，被 `-m gui` 静默跳过了 7 个）。改为 `QLineEdit()` + `setPlaceholderText`；
  只给 format/crs/矩阵集真实默认值；删掉死 helper `_new_edit`。
- **main_window flow 测试绑定仓库 app.yaml 内容**：真机会话往仓库 config/app.yaml 加了高德四图层后，
  「初始树只有天地图 / 加高德即新分组」断言失效（且再点模板加高德·影像变成去重 no-op）。改造成
  `_map_config_only(tmp_path, preset)` **最小确定性 fixture**（仅模板模块生成的一条天地图·影像，url 与内置模板
  同源，qgis: 顶层键收尾——append 已测形状），测试不再随仓库配置漂移。
- uri 测试解析 wms 连接串时 `split("&url=")` 找不到分隔——wms 串以 `url=` 开头（无 `type=xyz&` 前缀），改按 `url=` 拆。

## 遗留 / 注意

- WMS/WMTS/ArcGIS 首载走网络（capabilities / 服务自发现）；自动测试一律不构造非 xyz 图层，避免离网阻塞。
- 鉴权（token/basic）本轮不做；服务需匿名可读。
- 真机/联网手动验证留待用户侧：双击各条出图；`arcgis` 分支如真机实测需 `url=` 包一层，只改
  `build_online_basemap_layer` 的 arcgis 分支一处。
- 仓库 `config/app.yaml` 现已含高德四图层（真机会话加入）；天地图 tk 仍多处重复需换 key 全同步。
- git 工作区改动未提交（feature 分支 dev）；建议 `git add` 后用户审阅提交。
