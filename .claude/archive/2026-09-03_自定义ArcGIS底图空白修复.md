# 自定义添加的 ArcGIS 底图「提示已添加但画布空白」修复

> **后续更正**（2026-09-03，见 [[2026-09-03_在线底图新增FeatureServer矢量类型]]）：
> 本文末尾「arcgisfeatureserver 全无效、不要走这条路」的结论是用错端点——当时拿
> `…/MapServer/0` 喂 FeatureServer provider。实测该 provider 对本打包 QGIS 4.2 可用，契约是
> `crs='<EPSG:…>' url='…/FeatureServer/<图层id>'`（图层 id 在 URL 路径）+ 异步加载需 pump。
> 已按此落地 type=`arcgisfeature` 矢量类型，属性工具可识别要素。

日期：2026-09-03

## 背景

承接 [[2026-09-03_在线底图右键添加自定义底图]]。用户报告：把本地 ArcGIS 服务
`http://127.0.0.1:6080/arcgis/rest/services/江西省县级行政区域/MapServer`（矢量县界
MapServer）添加为自定义底图后，日志「已添加在线底图」、图层 isValid=True，但画布空白。

裁决（AskUserQuestion，均定稿）：
- 在 QGIS 里是用 **「ArcGIS REST 连接，加矢量面」** 加载的，加载后是**矢量显示**。
- 应用内目标 = **照 QGIS 效果即可**。
- 用户给出权威图层属性（决定性证据）：
  `提供程序 arcgismapserver`、`源 format='PNG32' layer='0' url='http://127.0.0.1:6080/.../MapServer'`。

## 根因

QGIS 4.2 的 **`arcgismapserver`（栅格）provider 需要参数串 URI**：
`format='PNG32' layer='0' url='<MapServer>'`（动态 /export，服务端把矢量面栅格化出图），
**不是裸服务 URL**。裸 `.../MapServer` 也能 isValid=True，但 extent 恒 0、永远画不出东西
（对 World_Imagery 影像、USA 矢量 MapServer 均复现）。

误导项（已排除）：QGIS 配置文件把 ArcGIS 连接存成 `arcgisfeatureserver\items\...\url`，
看似矢量 provider `arcgisfeatureserver`；但实测 `QgsVectorLayer(..., "arcgisfeatureserver")`
对多家公共服务都 isValid=False，且用户的图层属性暴露真相是 **arcgismapserver 栅格**。不要走
arcgisfeatureserver 路。

## 做了什么

### 1. `app/core/domain/basemap.py`

- 新纯函数 `_encode_non_ascii(url)`：非 ASCII 字节 percent 编码，对已有 `%xx` 幂等。
- 新纯函数 `build_arcgis_uri(d, keys=None) -> str`（进 `__all__`）：
  ```
  format='<d.format or PNG32>'
    + (d.layers 非空 → layer='<layers>'
        elif url 以 /MapServer 结尾 → layer='0'        # 默认第一个子图层
        else 不写（ImageServer 整服务即影像）)
    + url='<encode(apply_key_placeholders(d.url, keys))>'
  ```
- `build_online_basemap_layer` arcgis 分支：`QgsRasterLayer(裸 url, …)` →
  `QgsRasterLayer(build_arcgis_uri(d, keys), …)`（其余 wms/wmts 分支不变）。

### 2. `app/env/config.py`

`OnlineBasemapDef.to_dict` arcgis 分支改写：非空 `layers`（子图层 id）/`format`（出图格式）
才写；原 elif 是 `elif self.type != "arcgis"`（arcgis 只写 url）。字段注释 + 类 docstring
更新为「layers = …arcgis 子图层 id；format = …arcgis 出图格式」。

### 3. `app/ui/dialogs/custom_basemap.py`

- arcgis 页加 **「子图层 ID（可选）」** QLineEdit（占位「留空 = 0（MapServer 第一个图层）」），
  用 QFormLayout 排版；`_ARCGIS_HINT` 重写说明动态出图 / 矢量面同样适用。
- `_validate` arcgis 分支：填了但非数字 → 「子图层 ID 应为数字（留空默认 0）」。
- `basemap_def` arcgis 分支：非空子图层 id 落 `data["layers"]`。

### 4. 无需改配置

`config/app.yaml` 现有 arcgis 条目无 `layers:` → 建层时默认 `layer='0'`，正好与 QGIS
用户实操（layer 0）一致，即出图。
