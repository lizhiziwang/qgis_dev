# 2026-08-28 通用工具条：取消选择工具

## 需求

通用工具条再加一个「取消选择」工具，点击后取消所有当前选择的要素。

## 改动

- `app/ui/main_window/tool_bar.py`：
  - 按钮列表在「框选」之后、「属性」之前插入 `("取消选择", "clear_selection")`
  - docstring「一次性动作」列表补「取消选择」（与全图/刷新/测试/质检/分析一致）
- `app/ui/main_window/main_window.py`：
  - `callbacks` 加 `"clear_selection": self._on_clear_selection`
  - `_on_clear_selection()`：遍历 `project.mapLayers()`，矢量图层且有选择的调
    `layer.removeSelection()` 清空，随后 `QTimer.singleShot(0, self.canvas.refresh)`
- `app/ui/common/tool_icons.py`：`_GLYPHS` 加 `"clear_selection": "\uf057"`
  （times-circle，× 圈，Font Awesome 5 Solid）
- `tests/ui/main_window/test_tool_bar_highlight.py`：
  - `test_only_map_tools_are_checkable`：一次性动作断言列表加「取消选择」
  - 新增 `test_clear_selection_clears_all_vector_layers`：独立 project + 3 要素
    图层，选中 2 个 → 点击 → 选择清空；**当前激活的框选工具高亮保持**

## 关键设计 / 非显然点

1. **清所有图层**的选择（不限于当前图层），符合「取消所有当前选择的要素」；
   无选择时跳过 `removeSelection`（不触发无谓信号）。
2. **QGIS 4.2 API**：`QgsVectorLayer.clearSelection()` 不存在，用
   `removeSelection()`（dir 探测确认）。
3. **图标必须存在**：`tool_icons.icon()` 对未知 key 抛 KeyError，且发生在
   `MainWindow` 构造期（工具条 build）→ 忘记加图标会让所有依赖 `win` fixture
   的测试 setup 直接 ERROR。
4. 刷新走 `QTimer.singleShot(0, ...)`，遵守仓库「不在 Qt 事件栈内 refresh」约束。
5. 一次性动作不参与高亮：不改 `_active_key`、不清地图工具勾选态 → 点「取消选择」
   后框选/点选等工具状态保持。
