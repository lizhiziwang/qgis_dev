# 分析工具对话框 UI 改版 + 缓冲距离单位支持

日期：2026-08-07
分支：dev
范围：`app/ui/docks/tools_dock.py`、`app/ui/dialogs/buffer.py`、`app/ui/dialogs/vector_tile.py`、`app/ui/common/algo_desc.py`（新增）、`app/core/domain/buffer/service.py`

## 背景

归档历史（`2026-08-07_矢量工具崩溃修复.md` / `2026-08-07_缓冲区字段长度修复.md`）确认缓冲区工具已恢复正常。本次会话从回顾归档出发，接着做两件事：分析工具 UI 改版 + 缓冲距离单位支持。

## 做了什么

### 1. 分析工具 UI：左树右描述 → 改为对话框左参数右描述

- **用户澄清过程**：最初按「分析工具窗口 UI 改成左右两部分、右边展示算法描述」把 `tools_dock.py` 改成 QSplitter 左树右描述；用户随后澄清指的是**点击工具后弹出的参数对话框**，不是 dock。
- **抽共享模块**：新建 `app/ui/common/algo_desc.py` —— `algorithm_description_html(code)`（processing 注册表 `displayName` + `shortHelpString` 优先，仓库内 `_ALGO_FALLBACK_DESC` 中文兜底）+ `make_description_browser(code)`（只读 QTextBrowser + `TEXT_BROWSER_QSS`）。工具树与对话框共用同一套描述逻辑。
- **对话框改版**（`buffer.py` / `vector_tile.py`）：原「参数在上、描述在下一整块」垂直布局 → **QHBoxLayout 左参数（stretch 3）+ 右算法描述（stretch 2）**，进度条/按钮栏保持底部。移除旧 `QGroupBox` 描述块及其导入；`BufferDialog` 最小尺寸 520×440 → 760×520（右栏需要宽度）。
- **dock 定稿**：用户要求去掉 dock 内的算法描述 → `tools_dock.py` 恢复为纯工具树（去掉 QSplitter / 描述面板 / algo_desc 引用），点击节点照旧弹对话框。

### 2. 缓冲距离单位支持（米/千米/英尺/度/厘米…）

- **API 探测**（真实 QGIS 3.40）：本 build **没有** `QgsDistanceArea.convertLength`，用 `QgsUnitTypes.fromUnitToUnitFactor(src, dst)` 线性倍率换算；枚举值 Meters=0/Kilometers=1/Feet=2/NauticalMiles=3/Yards=4/Miles=5/Degrees=6/Centimeters=7/Millimeters=8/Unknown=49；`crs().mapUnits()` 投影→0（米）、地理→6（度）。
- **`service.py`**：`BufferJob` 新增 `distance_unit: Optional[int] = None`（默认 None=已按图层单位，向后兼容旧调用）；新增 `_to_layer_units(job)` 按图层 CRS `mapUnits()` 换算 `DISTANCE`；`run()` 里 `DISTANCE` 用换算值。
- **`buffer.py`**：缓冲距离改成一排横向布局（`QDoubleSpinBox` 数值 + `QComboBox` 单位下拉，9 项），`_on_execute` 把 `distance_unit` 传入 `BufferJob`。
- **`algo_desc.py`**：buffer 兜底描述更新为「距离可按所选单位输入，自动换算为图层坐标系单位」。

## 关键结果

- **单位换算验证**（真实 QGIS 离屏）：100米→米=100；1千米→米=1000；1英尺→米=0.3048；1厘米→米=0.01；地理图层 1000米→度≈0.00898。端到端 buffer：投影层 1km→米、地理层 0.01 度均成功输出 1 要素。对话框单位下拉 9 项齐全、默认「米」。
- `py_compile` 全部通过。
- 向后兼容：`distance_unit=None` 时行为与旧版一致，现有回归测试（`tests/core/domain/buffer/`）不受影响。

## 遗留事项 / 观察

- `_to_layer_units` 对地理图层用 `fromUnitToUnitFactor` 线性近似（1 度≈111319.49 米），高纬度区有偏差——对缓冲工具够用；如需精确可改用 `QgsDistanceArea` 按参考点测量。
- dock 里若以后要加描述，直接复用 `algo_desc.py` 即可（本次已抽好）。
- `vector_tile.py` 对话框沿用 BaseDialog 默认 800×600，未像 buffer 单独收敛宽度；如需可调整。
