# 通用工具条「在线底图」按钮 + 右侧 Dock + 右键模板入库

日期：2026-09-02

## 背景

需求（用户）：「通用」tab 工具栏加「在线底图」按钮，点击后右侧显示 Dock，列出
**天地图（影像/矢量/标注）+ 高德（影像/标注/矢量/路网）**图层清单。
**Dock 空白处右键菜单需支持添加在线底图。**

关键歧义裁决（会话中途用户纠正）：右键菜单的「添加在线底图」**不是**把瓦片直接加载到
画布（我最初实现），而是**往 Dock 树里新增一种底图类型**。
追问定稿：数据来源 = **内置模板清单**（不做自由 URL 弹窗）；持久化 = **写回 `config/app.yaml`**
（重启仍在）。

架构定稿（前序 AskUserQuestion）：图层清单配置驱动（`map.online_basemaps`），高德 key/URL 由
用户后续提供，本轮高德按公开 URL 模板先行补齐。

## 做了什么

### 1. 内置模板清单 `app/core/domain/online_basemap_templates.py`（新）

`ONLINE_BASEMAP_PRESETS: list[OnlineBasemapDef]`：
- 天地图 影像(img_w)/矢量(vec_w)/标注(cva_w) 三条完整 URL（tk 与 base_tile 同一把，
  referer=`https://www.tianditu.gov.cn/`，zmin 0/zmax 18）。
- 高德 影像(style=6)/标注(style=7)/矢量(webrd01 style=8)/路网(style=8) 四条占位，
  zmin/zmax 各异。
- 模块顶层不 import qgis.core（保持可离屏测试）。

### 2. Dock 重写 `app/ui/docks/online_basemap_dock.py`（新语义）

- 签名 `OnlineBasemapDock(parent=None, on_add=None, on_add_template=None)`：
  - `on_add`：双击 / 叶子右键「添加到画布」→ 把瓦片图层加载进工程。
  - `on_add_template`：右键「添加在线底图」→ 把一条内置模板插进 Dock 树（回调到 MainWindow 持久化）。
- `_append_add_submenu(menu)` 按模板 group 首现序分组建子菜单；**已在树里的模板（url 相同）置灰**。
- 右键命中：叶子 →「添加到画布」+ 分隔 +「添加在线底图」；分组 →「展开/折叠」+「添加在线底图」；
  空白 →「添加在线底图」。全部经 `_add_template` → `_on_add_template`。
- **修复 late-binding 闭包坑**：菜单 action 的 lambda 需 `lambda checked=False, d=d:` 默认参绑定，
  否则所有条目都触发最后一个模板。

### 3. config 文本写回 `app/env/config.py`

- `OnlineBasemapDef.to_dict()`：有序 dict {group, name, type, url, [referer], zmin, zmax,
  [enabled 仅 False 时省写]}，镜像 app.yaml 手写风格。
- `append_online_basemap_to_yaml(path, d)`：**文本插入**（PyYAML safe_dump 会丢注释，不可用），
  用缩进宽度比较定位 `online_basemaps` 末条目体，插到清单尾部注释之前，写回后重解析返回新清单。
- 缩进判断要点：按 `len(line)-len(line.lstrip())`（缩进宽）而非全行长判断条目边界，
  否则会吞掉尾随注释块。

### 4. MainWindow 接线 `app/ui/main_window/main_window.py`

- `_map_config_path()`：`QGIS_DEV_CONFIG` 环境变量可覆盖 config 路径（测试注入临时副本用）。
- `_on_online_basemap()`：懒建单例 dock + `addDockWidget(RightDockWidgetArea)` + 每次 `set_layers` 刷新。
- `_add_online_basemap_template(d)`：同 url 已存在 → messageBar 提示「已在在线底图清单中」返回 True
  （去重）；否则 `append_online_basemap_to_yaml` → 重读 → 刷新 dock 树 → messageBar「已写入
  config/app.yaml」。异常 try/except 记日志 + Critical。
- 画布加载路径 `_add_online_basemap`（原实现）保留：referer 预处理器 + build_base_tile_layer +
  同源去重 + 进「参考图层」顶部。

### 5. `config/app.yaml`

- 注释头更新为新语义（右键模板来自 `online_basemap_templates.py`，写回本清单）；删除原高德注释示例块
  （模板模块已覆盖）。仍只配天地图三图层。

## 遗留 / 注意

- **qgis_app teardown 偶发原生崩溃**（Windows access violation，tests/ui/conftest.py:78
  `sip.delete(w)` 处）：既有历史问题（MainWindow 参与时偶发），断言从不失败，仅进程级概率崩溃。
  本功能新增的 QAction/QIcon 把它从 ~0% 放大到 ~37%（概率性，非确定性，小样本曾误判归因 icon）。
  未硬化 fixture（如每测 sip.delete）——待用户决定。
- dock 测试的 `win` fixture 仍是 `yield w; w.close()`，未 show；teardown 崩溃与之同源。
- 高德图层走公开 style URL（webst01/webrd01），用户如提供正式 key/URL，仅需改
  `online_basemap_templates.py` 里对应条目（或直接补 yaml），无代码改动。
- 天地图 tk 在 base_tile 与清单三 URL + 模板模块多处重复；换 tk 需全同步（yaml 注释已写明）。
- git 工作区改动未提交（feature 分支 dev）；建议 `git add` 后由用户审阅提交。
