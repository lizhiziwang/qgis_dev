# 2026-08-14 属性工具识别栅格波段值

## 背景

用户反馈：主窗口工具条「属性」工具（`tool_bar.py` 的 identify 回调 →
`FindFeatureTool`）无法识别栅格图层。进一步确认需求：点击栅格后要能拿到
点击位置像元的**波段值**。

## 根因（探针逐项定位）

识别本身是通的（画布渲染后 `QgsMapToolIdentify.identify` 默认 `AllLayers`
能返回栅格像元结果），全挂在**下游展示层**：

1. `FindFeatureTool` 直接调继承的 `QgsMapToolIdentify.identify`（绕过了
   `FeatureIdentifyService`），拿到的栅格结果 feature 是像元多边形；
2. `FeatureInfoDock._load_info` 对栅格调 `layer.fields()` → **AttributeError**
   （`QgsRasterLayer` 没有 `fields()`）；
3. `_show_highlight` 用 `QgsHighlight(canvas, feature, layer)` → **TypeError**
   （栅格没有要素高亮 API）。

另外确认：像元波段值在识别结果的 `mAttributes` 里（如 `{'Band 1': '137'}`），
要素几何是点击的像元格子；`QgsHighlight(canvas, geometry, layer)` 几何重载
**可以**高亮栅格像元。

## 做了什么

- **`app/core/domain/identify/service.py`**
  - `IdentifyResult`：图层类型放宽为 `QgsMapLayer`，`feature` 可为 None，新增
    `raster_values: dict`（波段名 → 值）、`is_raster` 属性（`isinstance(layer,
    QgsRasterLayer)`，比 `layer.type()==` 更稳，也兼容测试里的 MagicMock 图层）、
    `fid` 对无 feature 返回 -1。
  - `FeatureIdentifyService.identify`：对栅格结果取 `mAttributes` 为
    `raster_values` 并保留像元几何；矢量分支逻辑不变。
- **`app/ui/tools/find_feature.py`**：工具改走 `identify_service.identify`
  （消除绕开 service 的旧路径）；`_show_highlight` 对栅格改用
  `QgsHighlight(canvas, geometry, layer)` 几何重载高亮像元格子。
- **`app/ui/docks/feature_info_dock.py` / `app/ui/dialogs/feature_info.py`**：
  `show_feature`/`_load_info`/`_copy` 加栅格分支——显示点击坐标（像元几何
  质心）与各波段值表格，复制为纯文本。

## 顺带修复（迁移遗留）

探针发现 QGIS 4.2 里 `QgsGeometry.asPointXY()` 已移除（改名 `asPoint()`），
点要素「复制信息」路径会崩。已在两处 copy 方法（含栅格坐标提取）全部改为
`asPoint()`。

## 关键结果

真实 QGIS 环境验证全通过：
- 双波段栅格点击 → `raster_values={'Band 1': '137', 'Band 2': '42'}`；
- 工具点击 → 栅格几何高亮创建 + `show_feature_info` 收到栅格结果；
- Dock 渲染含波段值与坐标，复制功能正常；
- 矢量回归：混合图层下矢量要素仍正确识别（属性保留）；
- 既有 3 个 identify service 单测逻辑复刻全部通过（MagicMock 图层不误判栅格）；
- 模块导入冒烟、点要素复制含坐标均正常。

## 遗留事项

- 混合图层点击矢量点上盖着栅格时，`identify` 返回顺序是栅格在前、工具取
  `results[0]` 会先显示栅格值——旧代码在该场景直接崩溃，现为改善，未改选择逻辑。
- `app/ui/flow_editor/` 仍为 git 未跟踪模块。
