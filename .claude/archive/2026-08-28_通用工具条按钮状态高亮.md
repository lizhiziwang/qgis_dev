# 2026-08-28 通用工具条：按钮状态高亮

## 需求

所有工具按钮添加状态显示：当前使用的工具按钮高亮。例：使用分屏（卷帘/地图对比）
工具时其按钮高亮。

## 改动

- `app/ui/main_window/tool_bar.py`：`ToolBar` 增加两类状态按钮——
  - 地图工具（`_TOOL_KEYS`：pan / select_point / select_box / identify /
    zoom_in / zoom_out / swipe）：**单选高亮**，跟随画布激活的 `QgsMapTool`；
  - 会话型工具（`_SESSION_KEYS`：qmap_compare）：**独立开关**，会话存活期间
    常亮，不受地图工具切换影响；
  - 一次性动作（zoom_full / refresh / test / quality / analyse）不可勾选。
  - 新增 `set_active(key)`（单选，跳过会话型）、`set_session_active(key, active)`
    （独立开关）、`active_key()`（测试用）；`_add_action` 按 key 设置 checkable。
- `app/ui/main_window/main_window.py`：
  - `_build_tool_bar` 里 `canvas.mapToolSet.connect(self._on_map_tool_set)`；
  - `_tool_key(tool)`：工具对象 → 按钮 key（pan/zoom 用身份比较，动态工具
    PointSelectTool / RectSelectTool / FindFeatureTool / SwipeTool 用类名映射）；
  - 各 `_on_*` 回调 `setMapTool` 后显式 `set_active(key)` —— **必须**：见关键点 4；
  - `_on_swipe` 两个分支（恢复旧会话 / 新建）都 `set_active("swipe")`；
  - `_on_qmap_compare`：启动 → `set_session_active("qmap_compare", True)`，
    停止 → `False`（地图对比无地图工具，按钮即停止入口）。
- `app/ui/common/theme.py`：`toolbar_qss` 勾选态从 `toolbar_hover`（与 hover 同色
  不明显）改为 **主题强调色 `input_focus` 半透明淡染（alpha 36）+ 底部 2px 下划线**，
  与 Tab 选中下划线风格一致；新增 `_with_alpha()` 辅助函数（hex → rgba）。
- `tests/ui/main_window/test_tool_bar_highlight.py`（新）：6 个测试（可勾选集合 /
  默认平移高亮 / 切换工具高亮迁移含重复点击 / 选择与识别高亮 / mapToolSet 信号
  驱动 / 地图对比会话独立高亮）。
- 既有测试适配：`test_qmap_compare.py` / `test_swipe.py` 的 `_FakeWin` 桩补
  no-op `tool_bar_builder`（真实 `_on_*` 会调 `set_active` / `set_session_active`）。

## 关键设计 / 非显然点

1. **两个独立高亮槽**：地图工具单选（radio）+ 会话型开关，可同时亮（例：地图
   对比会话运行中 + 正在平移 → 两按钮都亮，状态都真实）。

2. 会话存活 vs 工具激活的语义：卷帘是地图工具 → 单选；地图对比无地图工具 →
   会话独立常亮。切平移工具时卷帘按钮取消高亮但覆盖层仍在（视觉上分屏还在）；
   再点「卷帘对比」恢复分隔条拖拽并重新高亮。

3. QToolBar 里 `QAction.setCheckable(True)` + `setChecked` → 内部 QToolButton
   呈现 `QToolButton:checked`，QSS 选择器可直接命中（已像素级验证）。

4. **`setMapTool(同一工具)` 不触发 `mapToolSet`**（实测）→ 重复点击已激活工具的
   按钮时 QAction 自动翻转勾选态，回调里必须显式 `set_active(key)` 恢复；否则
   按钮会变成"未勾选"却仍是激活工具。

5. `mapToolSet` 携带工具对象（或 None），槽签名直接接收；`unsetMapTool` 触发
   `mapToolSet(None)` → 全部取消高亮（Esc 退出卷帘/框选后无激活工具，诚实显示）。
