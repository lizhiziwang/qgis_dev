# 2026-08-08 自定义标题栏 + 主题系统统一全局配色

## 做了什么

### 1. 无边框自定义标题栏（前期）
- 新增 `app/ui/main_window/title_bar.py`：应用图标 + 标题 + 用户信息（头像/用户名）+ 主题切换按钮 + 最小化/最大化/关闭，拖动/缩放由 `MainWindow.nativeEvent` 拦截 `WM_NCHITTEST` 交给系统。
- 修复 Aero Snap 贴边吸附：`WM_NCLBUTTONDOWN`(HTCAPTION) → `ReleaseCapture()` + `SendMessageW(SC_MOVE|HTCAPTION)`；双击最大化走 `WM_NCLBUTTONDBLCLK`。
- 非 Windows 平台拖动兜底：`QWindow.startSystemMove()`（Qt 5.15+）。
- 标题栏配色对齐窗体主色（#f5f6f7 → #f0f0f0）。

### 2. 主题系统（theme.py）
- `Theme` frozen dataclass + `THEMES` 四套主题（浅色/深色/蓝色/绿色）+ `ThemeManager` 单例（QSettings `ui/theme`，`theme_changed` 信号）。
- 渲染函数：`title_bar_qss / toolbar_qss / window_qss`（主窗体 chrome，设到窗体自身）；标题栏加调色盘按钮 + 主题菜单。
- 地图画布底色随主题：`canvas.setCanvasColor(theme.canvas_bg)`。
- 工具条 / 主窗体 / 标题栏订阅 `theme_changed` 自动重绘。

### 3. 弹窗、右键菜单等所有要素统一走主题（本阶段核心）
- `Theme` 新增 10 个通用控件字段：`text_secondary / text_error / input_bg / input_border / input_focus / btn_bg / btn_hover / btn_pressed / panel_bg / panel_border`，四套主题配齐。
- 新增 **`app_qss(theme)`**：QApplication 级全局 QSS，覆盖 `QDialog / QMenu / QMessageBox / QToolTip / QPushButton / QLineEdit / QComboBox / QCheckBox / QRadioButton / QGroupBox / 各类 Table/Tree/List / QHeaderView / QTextBrowser / QScrollBar / QSplitter / QProgressBar / QTabWidget / QToolButton`。
- 新增 `canvas_zoom_qss(theme)`；`apply_app_tooltip_style` 泛化为 `apply_app_theme`（设全量 `app_qss`），旧名保留别名。
- **关键架构点**：弹窗/右键菜单/ToolTip 是顶层窗口，不吃主窗体 `setStyleSheet`，只有 QApplication 级 QSS 能覆盖到。
- `bootstrap._ensure_qgis_application` 创建 app 后立即 `ThemeManager.instance()`，登录弹窗等主窗口之前的顶层窗口也有主题。

### 4. 迁移硬编码样式
- `styles.py` 清空为兼容桩模块（`DIALOG_BASE_QSS / TEXT_BROWSER_QSS / CANVAS_ZOOM_* / apply_*_style` 删除）。
- 移除本地 QSS：`login.py`（副标题/错误走 `loginSubtitle/loginError` object-name，颜色在 app_qss）、`custom_attr.py`、`check_editor.py`（标题走 `DialogTitle`）、`execute_sql.py`、`log_dock.py`、`algo_desc.py`（提示色随 `text_secondary`）、`widgets.py`（刷新按钮走 `FlatButton`）、`feature_info.py / feature_info_dock.py`（HTML 副标题/隔行/分隔线/占位符从主题取色）、`canvas_zoom.py`（用 `canvas_zoom_qss` + 订阅主题切换）、`resources/__init__.py`（删未用的 `apply_app_style`）。

## 关键结果

- 全部改动文件 `py_compile` 通过；所有受影响模块（含 `main_window`）import 冒烟通过。
- 运行态冒烟：切 4 套主题，`app.styleSheet()` 含对应颜色、弹窗内 label 文字色/输入框底色实际跟随主题（如深色 `input_bg=#232528`）；登录框、质检配置框、SQL 框直接构造无崩溃，本地 `styleSheet` 为空（颜色全走全局主题）。
- 测试环境注意：GUI 冒烟须用 `QgsApplication(bytes argv, True)`（裸 `QApplication()` 在该环境 0xC0000409）；`QColor.name()` 返回小写 hex（`#d33` → `#dd3333`），断言需用 `QColor` 归一化比较。
