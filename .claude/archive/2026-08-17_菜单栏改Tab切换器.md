# 主窗口菜单栏改造为 Tab 切换器

> 2026-08-17。用户："把菜单栏改造一下，改成类似 tab 切换的效果，点击不同的 tab，
> 对应下方的 toolbar 也换成对应的。现在默认的 toolbar，新建一个通用 tab 放进去"。

## 方案

原顶部 `QMenuBar` 换成 `QTabBar`（放在无边框 chrome 里、标题栏正下方），点 tab
切换**互斥显示**对应工具条（QMainWindow 工具条区同一行内只留当前 tab 的那条）：

| tab  | 工具条                                        | 来源 |
|------|-----------------------------------------------|------|
| 文件 | 新建工程/打开工程/打开文件/退出（文字按钮）      | 原「文件」菜单 |
| 查看 | 日志/流程节点编辑器（文字按钮）                 | 原「查看」/「流程」菜单 |
| 编辑 | 「编辑工具」DigitizingToolbar                 | 原有编辑工具条 |
| 通用 | 「地图工具」（pan/识别/缩放/质检/分析/全图/刷新/测试） | 默认工具条 |

- 原菜单项全部保留为对应 tab 工具条上的 `QAction`，**快捷键不丢**
  （Ctrl+N / Ctrl+Shift+O / Ctrl+O / Ctrl+L / Ctrl+Shift+F / Ctrl+Q）。
- 菜单栏属性：`:menubar` → `:_tab_bar`（`objectName="ChromeTabBar"`，供 QSS 精确作用）。

## 改动文件

- `app/ui/common/frameless.py`：`enable_frameless` 新增 `with_tab_bar=True` 分支——
  在 chrome（title_bar + QTabBar）取代 `with_menu_bar`（QMenuBar）；`with_menu_bar`
  保留向后兼容。`MainWindow` 改传 `with_tab_bar=True`（唯一旧传参者）。
- `app/ui/common/theme.py`：`window_qss` 新增 `QTabBar#ChromeTabBar` 系列规则
  （选中下划线用 `input_focus`，hover 用 `menu_hover`）——**objectName 限定**，
  不碰 dock/弹窗里由 `app_qss` 样式的普通 QTabBar。
- `app/ui/main_window/main_window.py`：删 `_build_menu_bar`/`MenuBar`，新增
  `_build_tabs`（建 4 个 tab + `_tab_toolbars` 索引映射）+ `_build_file_toolbar` /
  `_build_view_toolbar` + `_on_tab_changed`（互斥 `setVisible`）。
- 删除 `app/ui/main_window/menu_bar.py`（无其他引用）。

## 测试

新增 `tests/ui/main_window/test_tab_bar.py`（4 个 gui 用例，构造 MainWindow）：
- 4 个 tab 文本、默认激活「通用」且只显示地图工具；
