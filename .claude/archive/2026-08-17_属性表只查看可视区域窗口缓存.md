# 属性表改为"只查看可视区域"——fid 列表 + 按需取要素窗口缓存

> 2026-08-17。前置：`2026-08-17_属性表过滤大数据量卡死.md` 已把过滤/流式挪到后台线程，
> 但模型仍**驻留全部已加载的 QgsFeature**（含几何+属性），2M+ 靠 `MAX_MODEL_FEATURES=100k` 截断。
> 用户追问"表格窗口不能只查看可视区域吗"——答案是可以，且这正是 QGIS 自带属性表架构。

## 方案（QGIS 属性表同款架构）

模型**只存结果 fid 列表**（2M 条 ≈ 70MB 可接受），**不再驻留要素对象**；
QTableView 渲染可视行时经 `feature_at(row)` 按 fid 从图层**按需取要素**，
用 LRU 缓存（`MAX_FEATURE_CACHE=2000`，几 MB）按滚动窗口淘汰。

- 内存不随结果总量增长：2M+ 也能完整浏览全部结果，截断上限仅为防失控兜底。
- 同时迭代更快：worker 只取 fid 时请求裁掉几何/属性（`Flag.NoGeometry` + `setNoAttributes`），
  不构造 geometry、不物化属性值，每要素几字节。

## 改动（`app/ui/docks/attribute_dock.py` + 测试）

- **worker**：`_prepare_filter` 非组合路径（无过滤/纯 show_ids/纯表达式）加
  `Flag.NoGeometry` + `setNoAttributes`（组合路径要 python 侧求表达式，保留属性）；
  `chunk_ready` 改发 `list[int]` fid；`_stashed` 探测要素仍存 QgsFeature，入队只取 `.id()`。
- **模型**：`self.features` → `self._fids: List[int]` + `self._feature_cache: dict[int, QgsFeature]`。
  - `feature_at(row)`：缓存命中即返；未命中 `layer.getFeature(fid)`（shapefile 走 .shx 偏移 O(1)，
    内存图层 O(1)），LRU 插入；要素已删返回 None。
  - `data()`：第 0 列直接返 fid（不取要素）；其余列经 `feature_at`。
  - `setData()`：按 fid `changeAttributeValue`，成功后弹掉缓存条目（下次重取新值）。
  - `_insert_fids()`：替代 `_insert_features`，仍走 begin/endInsertRows 渐进追加。
  - `MAX_MODEL_FEATURES` → `MAX_MODEL_FIDS = 5_000_000`（仅兜底，正常 2M+ 不触发）；
    新增 `MAX_FEATURE_CACHE = 2000`。
  - `_sync_load_all`（小图层同步路径）也只取 fid（该路径不可能含 python 侧表达式，安全裁减）。
- **widget**：`_refresh_load_state` 用 `model.rowCount()`；`_show_context_menu` 用 `feature_at`（+None 守卫）。
- **测试**：`_ids(model)` → `list(model.fids)`；右键用例改用 `fids[0]`/`feature_at(0)`；
  截断用例改 patch `MAX_MODEL_FIDS`；新增 `test_feature_at_on_demand_and_cache_bounded`
  （按需取、缓存 ≤ cap、淘汰后重取仍正确）。**18/18 通过**，`ruff --select F,E9,I` 干净。

## 关键探针事实（QGIS 4.2）

1. `setFlags(Flag.NoGeometry)` + `setNoAttributes()` 后 `getFeatures` 仍返回 `feat.id()`，
   表达式过滤 + 裁减组合正常（`"name"='n3'` → `[4]`）。
2. `layer.getFeature(fid)` 返回**完整**要素（几何+属性）；缺 fid 返回 invalid/None 不崩。
3. 主线程 `getFeature` 与 worker 线程 `getFeatures` 并发：QGIS 读锁为共享读锁，多个读者共存，无死锁。

## 验证（30 万带属性 memory 图层，`_probe_fid_window.py` 已删）

- 300k 全量加载 1.89s 完成（GUI 不阻塞），`data()` 行 0/1000/150000/299999 取值全部正确。
- 一屏渲染（50×3 cells）0.0000s（缓存命中）；跳中部区域再渲染 0.0000s。
- 全范围逐个 `feature_at`（300 次）后缓存 **399 ≤ 2000**，内存恒有界。
- 过滤 `"name"='n199999'` → 1 行，取值正确。
