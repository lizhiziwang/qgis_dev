# 缓冲区「无法将要素写入 OUTPUT」根因与修复

日期：2026-08-07
分支：dev
范围：`app/core/domain/buffer/service.py`（核心修复）、`tests/core/domain/buffer/`（新增回归测试）、memory gotchas 更新

## 背景

崩溃修复（`2026-08-07_矢量工具崩溃修复.md`）后，用户报告缓冲区工具对真实图层报新错误：

```
app.core.domain.buffer.service - __ERROR__ - native:buffer 执行失败 缓冲区结果:
无法将要素写入 OUTPUT
```

（`QgsProcessingException`，即英文 `Could not write feature into OUTPUT`）。用户确认输入图层是 ESRI File Geodatabase（.gdb）图层、未勾选 dissolve。

## 根因（阶段二分定位）

| 排除项 | 方法 | 结论 |
|---|---|---|
| 距离参数 | 0.01–100 度全失败 | 无关 |
| dissolve | 未勾选 | 无关 |
| wkb 类型 / 无几何 / GeoJSON / 虚拟层 / join / 虚拟字段 / subset / 空图层 / 重复输出名 | 逐类构造探针 | 均能正常缓冲，排除 |
| 单个要素 | 真实 GDB 逐要素写入复刻 sink | 6/7 成功，仅第 7 个失败 |
| 单个属性值 | 单属性真值测试 | 失败字段全是 String 短字段，值恰为字面 `'NULL'`（4 字符） |
| **字段声明长度** | 受控长度测试 | **决定性**：memory provider 严格拒绝超过字段声明长度的字符串值 |

**最终根因**：GDB/ArcGIS 导出图层中短代码字段的**声明长度小于实际数据**。如 `XIANG` 声明 3、`CUN` 声明 3、`LD_QS` 声明 2、`BH_DJ` 声明 1……但空值被 ArcGIS 工具写成字面量 `'NULL'`（**4 字符**）。QGIS memory provider（`addFeatures` 与 `QgsVectorLayerFeatureSink`）严格校验长度，超长值写入即被拒 → 算法输出 sink 报「无法将要素写入 OUTPUT」。

受控长度测试数据：
```
len=3 'abcd'(4) -> False   len=3 'abc'(3) -> True   len=3 None -> True
len=4 'NULL'(4) -> True    len=50 'NULL' -> True
```
真实图层 `XIANG` 值 `['009','009','009','009','009','009','NULL']` —— 前 6 个要素短字段存 ≤3 字符真值（能写出），只有第 7 个要素存 4 字符 `'NULL'`（超长，失败），与"仅 feat6 写入失败"完全吻合。`'NULL'` 是表象，字段长度不匹配才是本质。

## 修复（service.py）

新增模块级函数 `_copy_with_widened_string_fields(layer)`：扫描一遍数据，把 String 字段声明长度放宽到实际最大值，拷贝成临时 memory 图层作为算法 INPUT；无需修正时原样返回零开销。`run()` 在 `processing.run` 前调用它。任何异常都 `logger.warning` 后退回原图层（保持原行为，修正只是增强）。附带发现：`addFeatures` 的 `errors` 列表即使成功也会填充（怪癖），判断只看 `ok`。

## 验证

- 真实 GDB：7/7 要素全部写出，结果 `XIANG` 长度 4；sanitize 前后 **350/350 属性逐项比对一致**。
- 健康 memory 图层（len=50 存 `'NULL'`）：不受影响，正常缓冲、字段长度不变。
- 宽字段层存 `'NULL'`：无需修正，正常。
- 新增回归测试 `tests/core/domain/buffer/`（沿用 `check/conftest.py` 的 `qgis_app` fixture 模式，`@pytest.mark.gui`，CI `-m 'not gui'` 跳过）：
  - GeoJSON 宽化逻辑（声明 0 → 实际 4，数据保真）
  - 长度足够时原样返回（no-op）
  - 真实 GDB 端到端 buffer 全量写出（数据缺失自动 skip，可用 `QGIS_BUFFER_GDB` 覆盖路径）
- 注：QGIS 运行环境未装 pytest，测试断言已用探针逐一镜像验证通过（`test_all`）。
