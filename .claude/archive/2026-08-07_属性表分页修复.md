# 属性表显示不全修复（分页 → 动态加载）

日期：2026-08-07
分支：dev
范围：`app/ui/docks/attribute_dock.py`、`tests/ui/docks/test_attribute_dock.py`

## 根因

属性表"数据不全"：旧实现 `_load_page()` 用 `QgsFeatureRequest.setOffset()` 分页，
而**本 QGIS 3.40 构建的 QgsFeatureRequest 没有 `setOffset` 方法**（`AttributeError`
被 `except Exception` 吞掉，页面永远返回 0 行）；旧代码还只 `setLimit(1.5*page_size)`
不带任何翻页入口，最多只能看到前几十条。

## 最终方案（用户要求：分页改为动态加载）

按用户要求从分页展示改为**动态加载**：初始加载总量的 **20%**，滚动到底或点击
"加载更多"再追加 20%，直至加载完。

### 模型 `PagedAttributeTableModel`
- `_refresh_totals()`：一次性取匹配 `where` 的全部要素 ID（`$id` 升序），
  得 `total_features` 与 `batch_size = max(1, ceil(total * 0.2))`。
- `load_more()`：从 `all_ids` 切片下一批，`setFilterFids(page_ids)` 取回完整要素，
  `beginInsertRows`/`endInsertRows` **追加**而非全量 reset（保留滚动位置）；
  `has_more` 属性判断是否还有未加载。
- `set_filter()`：重新统计，`beginResetModel` 后回到首屏 20%。
- 去掉 `current_page`/`total_pages`/`go_to_page`/`set_page_size`；
  `page_size` 参数保留仅兼容旧调用（main_window 传 50），内部不再按页。

### widget `PagedAttributeTableWidget`
- 去掉分页条（每页下拉 + 首页/上一页/下一页/末页 + 页信息）。
- 底部改为**状态标签**（"已加载 X / Y 条，滚动到底或点击加载更多" / "共 Y 条
  （已全部加载）"）+ **加载更多按钮**（`has_more` 时可用）。
- **滚动到底自动加载**：`verticalScrollBar().valueChanged` 接近底部时触发；
  经 `QTimer.singleShot(0)` 延迟到下一事件循环，避免 `endInsertRows` 同步触发
  滚动信号造成的重入。
- 筛选后 `scrollToTop` + 刷新加载状态。

## 关键结果

- 探针验证：120 条 / 批 24 → 滚动加载 24→48→72→96→120；筛选 `$id<=30` 重置为
  6/30；全部加载后按钮禁用、标签显示"已全部加载"；完整 dock 正常。
- 新增 7 个回归测试：批次=20%、逐批加载到全部、小数据批次至少 1 条、筛选重置、
  show_ids 子集、空图层、widget 按钮加载 + 状态文本。
- 全 GUI 套件 142 passed / 5 failed / 1 skipped；5 个失败为**既有债务**
  （check `value_range` 2 个 + messagebar `_get_bar` 3 个，与本次无关）。
- lint：改动文件 `--select F,E9,I` All checks passed。

## 踩坑

- **`QgsFeatureRequest.setOffset` 在本构建不存在**：新写翻页/加载更多不要依赖
  offset，用 `all_ids` 切片 + `setFilterFids`。
- 被 `except Exception` 吞掉的异常会把"接口不存在"伪装成"数据为空"——调试先
  裸跑 getFeatures 看真实报错。
- **Qt 信号重入**：`beginInsertRows`/`endInsertRows` 会同步触发滚动条
  `valueChanged`，滚动触发的加载必须 `QTimer.singleShot(0)` 延迟，否则重入。

## 遗留/备注

- `FeatureLoaderThread`（attribute_dock.py 顶部）已无引用，属迁自 legacy 的死代码，
  未删（避免无关改动）。
- `space_query.py` 里对 `PagedAttributeTableWidget` 的 import 是死 import，未动。
- 既有 5 个失败测试建议后续单独修（同 [[2026-08-07_重投影工具]] 记录）。

## 追加：属性表右键菜单「选中要素 / 缩放到要素」失效修复

### 根因
1. **缩放到要素**：`AttributeDock.zoom_to_map` handler 调用
   `topParent.zoom_to_layer_extent_transform(...)`，但 **MainWindow 没有这个方法**
   （`hasattr` 为 False），缩放被静默跳过，只执行了 selectByIds。
2. **选中要素**：widget 直接 `layer.selectByIds([fid])`，但 **selectByIds 不会自动
   刷新画布**，高亮不出现，用户以为没生效。

### 修复
- `MainWindow` 新增 `zoom_to_layer_extent_transform(extent, source_crs)`：范围做
  CRS 变换到画布坐标系后 `canvas.setExtent` + `canvas.refresh()`（复用
  `_zoom_to_layer` 的变换逻辑）。
- widget 右键「选中要素」改为经 `zoom_to_map.emit("selectFeature", ...)` 路由到
  dock handler，handler 选中后调 `_refresh_canvas()` 刷新画布。
- handler 对 `zoomTo` 的分支逻辑不变（MainWindow 方法就位后即可用）。

### 验证
- 端到端探针（真实 MainWindow + 画布）：`selectFeature` → 选中 [1] 且刷新；
  `zoomTo` → 选中 [1] 且 **canvas extent 移动**。复刻右键菜单 lambda 行为一致。
- 新增 3 个回归测试（selectFeature 选中+刷新、zoomTo 调用 transform、MainWindow
  方法存在）。
- 全 GUI 套件 145 passed / 5 failed（既有债务）；dock + 测试 lint 干净。
  main_window.py 的 9 个 F401/I001 为**既有债务**（import 行未动过）。

### 踩坑
- **`QgsRectangle` 没有 `isValid()`**（本构建）：用 `isNull()`；点要素的 0 尺寸
  包围盒不是 null，`canvas.setExtent` 能正常处理。
- `layer.selectByIds()` 只改选择集，**不刷新画布**——要显示高亮必须显式
  `canvas.refresh()`。

## 追加：状态栏比例尺失效 + 新增鼠标坐标显示

日期：2026-08-07
范围：`app/ui/main_window/status_bar.py`、`tests/ui/main_window/test_status_bar.py`（新增 7 个测试）

### 根因（比例尺"未生效"）

本 QGIS 3.40 构建的 `QgsScaleWidget(canvas)` **构造参数被忽略**：没有 `setCanvas`，
传入的 canvas 从未保存，控件永远显示默认 `1:1,000,000`，缩放/平移后也不更新
（scaleChanged 不会自动驱动它）。同时 `qgis.gui` 里没有 `QgsStatusBarScaleWidget` /
`QgsStatusBarCoordinatesWidget` / `QgsCoordinateWidget`。

### 修复
- 比例尺：`QgsScaleWidget()` 裸建 → `setMapCanvas(canvas)` → 连接
  `canvas.scaleChanged` → `setScaleFromCanvas()`；`scale()>1.0` 才同步
  （scale==1.0 是"未设置范围"哨兵值，避免显示怪异的 1:1）。
- 坐标：手写 `QLabel`（minWidth 150）接 `canvas.xyCoordinates`；
  空点 `QgsPointXY()`（鼠标离开画布时发出，`.isEmpty()` 判断）显示占位 "—, —"；
  按画布目标 CRS 格式化：地理坐标系 `f"{x:.5f}°, {y:.5f}°"`，投影坐标系
  `f"{x:.1f}, {y:.1f}"`。`QgsCoordinateFormatter.asPair` 只绑了 3 参重载
  （第 4 个 decimals 传 int 抛 TypeError），精度不够，直接手写格式。

### 验证
- 端到端探针（真实 MainWindow）：`setExtent`+`zoomByFactor` 后比例尺从
  `1:1,000,000` 更新到实际 `1:189,928`；`xyCoordinates.emit` 后坐标标签显示
  `116.39123°, 39.90123°`，空点复位 `—, —`。
- 新增 7 个回归测试：控件挂到状态栏、无范围时保留默认比例、随缩放同步、
  坐标更新/离开占位/地理度格式/投影数字格式。
- 全测试套件 152 passed / 5 failed（既有债务 value_range + messagebar _get_bar）/ 1 skipped。
- lint：改动文件 `--select F,E9,I` All checks passed。

### 踩坑
- `QgsScaleWidget` 在本构建是普通 QWidget（非 QComboBox），没有 `currentText`/`count`，
  别按 combo 用。
- `QgsPointXY()` 默认构造 x/y=0.0 且 `isEmpty()` True（没有 `isNull`），用来表示"离开画布"。
