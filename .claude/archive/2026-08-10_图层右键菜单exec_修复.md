# 2026-08-10 图层列表右键菜单崩溃修复（PyQt6 `.exec_` 移除）

## 问题

QGIS 4.2 / PyQt6 迁移后，图层列表右键菜单一打开进程就崩（exit 127、无 traceback），与之前的 show() 崩溃同类。

## 根因

PyQt6 完全移除了 `.exec_()`（`QMenu`/`QDialog`/`QApplication` 只有 `.exec()`）。迁移时的全局替换 `.exec_()` → `.exec()` 只命中了**空括号**调用；**带参数的 5 处** `menu.exec_(pos)` 全部漏掉：

- `app/ui/main_window/main_window.py:774`（浏览器 dock 右键）
- `app/ui/main_window/main_window.py:895`（图层右键 —— 用户报告的崩溃点）
- `app/ui/docks/attribute_dock.py:403`
- `app/ui/docks/tools_dock.py:243`
- `app/ui/dialogs/check_viewer.py:262`

右键路径：`customContextMenuRequested` → `context_menu_requested` 信号 → 槽 → `_build_layer_context_menu` → `menu.exec_(global_pos)`。`QMenu.exec_` 不存在 → 槽内 `AttributeError` 未捕获 → PyQt6 事件分发穿出 → 原生崩溃（与 memory 里 0xC0000409 同类）。

`legacy/` 下的 `.exec_` 不修（死代码，全仓无 `import legacy`）。

## 修复

5 处全部 `menu.exec_(...)` → `menu.exec(...)`。菜单构建路径其余 API（`QAction` 已在 PyQt6.QtGui、`Icons.remove()`、`addMenu`）均无 PyQt6 问题。

## 验证

- 探针 `.tmp/probe_context_menu.py`：完整引导（config→runtime→QgsApplication→initQgis→build_window→show）→ 塞内存点图层 → monkeypatch `QMenu.exec` 记录调用 → emit `layer_dock.context_menu_requested(pos)`（真实信号→槽链）→ 定时器关弹窗。结果：`menu.exec 被调用 1 次，rc=0`，EXIT=0。
- 全量测试：157 passed，1 skip（fastapi），EXIT=0。
- 探针已删；`grep '\.exec_' app/` 无残留。

## 记忆
