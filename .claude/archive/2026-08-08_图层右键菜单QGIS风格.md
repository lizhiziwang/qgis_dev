# 数据图层/参考图层右键菜单（QGIS 原生面板风格）

日期：2026-08-08
分支：dev

## 背景

用户请求 `@app/ui/docks/project_dock.py` 的数据图层/参考图层列表添加"跟 QGIS 图层列表
一样的右键菜单"。首版复用 app 既有自定义菜单，用户明确需求是更接近 QGIS 原生图层面板的
菜单，并选定了"更接近 QGIS 原生面板"方向。

`QgsLayerTreeView.menuProvider()` 在本构建返回 `None`（原生 QGIS 图层面板菜单由桌面
app shell 注入，裸 widget 拿不到），所以 QGIS 原生菜单需手工复刻。

## 做了什么

| 文件 | 改动 |
|---|---|
| `app/ui/docks/project_dock.py` | （此前会话已完成）新增信号 `layer_context_menu_requested(object, object)`；`data_view`/`ref_view` 设 `CustomContextMenu` 策略，`_on_view_context_menu` 用 `QgsLayerTreeModel.index2node` 解析图层并发出 `(layer, viewport 全局坐标)` |
| `app/ui/main_window/main_window.py` | 右键菜单重构为共享构建器 `_build_layer_context_menu`（图层树 `_on_layer_context_menu` 与工程 Dock `_on_project_dock_context_menu` 共用）。菜单项贴近 QGIS 原生顺序与条件：缩放至图层 → **放大至选中要素**（有选中才显示）→ 设为编辑图层 → 打开属性表 / 执行SQL（仅矢量）→ **重命名** / **复制图层** → 样式（编辑样式仅矢量 + 打开样式配置 + 保存样式 + **复制样式 / 粘贴样式**，粘贴无剪贴板时禁用）→ 移到参考/数据图层（创建工程后显示）→ 移除 / 导出（仅矢量，走 `QgsVectorLayerSaveAsDialog`）/ 属性。新增动作方法：`_zoom_to_selection`、`_rename_layer`、`_duplicate_layer`、`_copy_layer_style`、`_paste_layer_style`；`self._style_clipboard` 存样式 xml；新增 import `QgsMapLayerStyle`/`QgsRasterLayer`/`QgsWkbTypes`，删除不再使用的 `QgsMapLayer` |

## 关键实现点

- **重命名**：`layer.setName()` 自动同步树节点名，无需手动改节点。
- **复制图层**：矢量 → 内存副本 `QgsVectorLayer(f"{geom}?crs=...", name, "memory")` +
  `addAttributes(fields().toList())` + `updateFields()` + `addFeatures(list(getFeatures()))`；
  栅格 → 同源新 `QgsRasterLayer`；副本挂到原图层所在分组（`layerTreeRoot().findLayer(layer).parent()`），
  找不到才走 `_add_layer_to_project`。副本自动带上当前样式（`styleManager().addStyle + setCurrentStyle`）。
- **复制/粘贴样式**：复制存 `style(sm.currentStyle()).xmlData()`；粘贴用
  `sm.addStyle("pasted", QgsMapLayerStyle(xml)) + setCurrentStyle("pasted")`。

## 遗留事项 / 观察

- 离屏环境没有 raster 数据 provider（`Cannot instantiate the 'raster' data provider`），栅格菜单
  分支用未 validated 的 `QgsRasterLayer` 对象验证类型门控。
- 实机冒烟待用户复测：右键数据/参考图层树 → 各菜单项行为；复制图层后副本出现在同分组；复制/粘贴样式跨图层生效。
- 单点选中"放大至选中要素"：因点 bbox `isEmpty()` 为真，`_zoom_to_selection` 先 `isNull()` 判断、
  再对零面积框扩一圈（±0.001）后 setExtent，避免空范围。
- 探针与临时文件已清理；`.tmp/` 仅保留既有 `probe_sb*`/`probe_mw_sb*` 与 `pytest_qgis`/`run_gui_tests.py` 共用工具。
